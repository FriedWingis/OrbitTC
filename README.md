## 👨🏻‍💻 About the project

- <p style="color: red;">OrbitTC is a plugin built to securely manage in-game transactions while enhancing user experience. It intercepts purchases made through the server’s Tebex store and routes them to a confirmation inventory for player approval. This plugin was originally developed for the CosmicGalaxy Minecraft server. To comply with *CosmicGalaxy LLC's copyright, the project has been renamed and slightly modified.

*I am the sole owner and operator of CosmicGalaxy LLC.
</p>

- [Maven](https://maven.apache.org/)

## 💻 Getting started

**Clone the project and access the folder**

```bash
$ git clone https://github.com/FriedWingis/OrbitTC.git && cd OrbitTC
```

**NOTE: This plugin contains references to a private plugin named OrbitCore. You will need to remove and/or replace these references and imports in order to build the plugin.**
